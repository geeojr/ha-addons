# ha-addons

Home Assistant add-ons for the Geeo house.

| Add-on | What |
|---|---|
| [wx-alerts](wx-alerts) | NWS watch/warning watcher: per-level announce/push rules, templated voice announcements, pushes people who are inside an alert. Sidebar panel via ingress. |
| [evergy-sync](evergy-sync) | Hourly Evergy (Opower) usage + TOU-priced cost into long-term statistics. Own browser-free sign-in, one attempt per day. |
| [ev-stats](ev-stats) | Per-vehicle EV charging cost, efficiency and gasoline-equivalent sensors (rolling windows + long-term statistics) from the chargers' power and the cars' odometer / state of charge; EIA + AAA fuel prices. Sidebar panel via ingress. |

Install: Settings → Add-ons → Add-on Store → ⋮ → Repositories → add
`https://github.com/geeojr/ha-addons`.
